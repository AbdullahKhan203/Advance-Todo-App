# 🧠 Simple Definition

👉 **Refresh Token = a long-lived token used to get a new access token**

---

# 🧩 Why we even need it?

You already know:

* Access token (JWT) expires quickly (e.g. 15 min)
* After expiry → user is logged out ❌

👉 This is bad UX

---

# 💡 Solution = Refresh Token

👉 Instead of logging out user:

1. Access token expires
2. Use **refresh token**
3. Get **new access token**
4. User stays logged in ✅

---

# 🔄 Flow (VERY IMPORTANT)

### Step-by-step:

### 1. Login

Backend sends:

```json
{
  "accessToken": "short-life (15 min)",
  "refreshToken": "long-life (7 days)"
}
```

---

### 2. Store tokens

* accessToken → frontend (memory / localStorage)
* refreshToken → **HTTP-only cookie (BEST PRACTICE)**

---

### 3. API request

Frontend sends:

```http
Authorization: Bearer accessToken
```

---

### 4. Access token expires ❌

Backend responds:

```http
401 Unauthorized
```

---

### 5. Frontend uses refresh token

Calls:

```http
POST /refresh-token
```

with refresh token

---

### 6. Backend verifies refresh token

If valid:

```json
{
  "accessToken": "new access token"
}
```

---

### 7. Retry original request ✅

User doesn’t even notice anything

---

# 🔥 Real Life Analogy

👉 Access token = **entry ticket (short time)**
👉 Refresh token = **VIP pass to get new ticket**

---

# 🧠 Key Differences

| Feature  | Access Token    | Refresh Token       |
| -------- | --------------- | ------------------- |
| Life     | Short (minutes) | Long (days)         |
| Used for | API calls       | Getting new token   |
| Stored   | Frontend        | Secure (cookie/db)  |
| Risk     | Low             | High (must protect) |

---

# 🚨 Important Security Rule

👉 Never store refresh token in localStorage ❌
👉 Use:

```http
HTTP-only cookie ✅
```

---

# 🔥 Backend Example (simple)

## Login:

```js
res.json({
  accessToken,
  refreshToken
});
```

---

## Refresh route:

```js
app.post("/refresh-token", (req, res) => {
  const refreshToken = req.cookies.refreshToken;

  try {
    const user = jwt.verify(refreshToken, REFRESH_SECRET);

    const newAccessToken = jwt.sign(
      { id: user.id },
      ACCESS_SECRET,
      { expiresIn: "15m" }
    );

    res.json({ accessToken: newAccessToken });

  } catch (err) {
    res.status(401).json({ message: "Invalid refresh token" });
  }
});
```

👉 Access token expires → ❌
👉 Refresh token generates new access token → ✅
👉 User stays logged in
